# Routing templates

This directory contains client-specific routing templates.

These files are routing templates, not complete client configurations. The node
section still has to be generated by Sub-Store or filled from your own config.

## Files

- `mihomo.yaml`: Mihomo / OpenClash routing template. Use it with 3x-ui
  `subClashRules` or a Sub-Store `mihomoConfig` file.
- `stash.yaml`: Stash / Clash-like routing template.
- `shadowrocket.conf`: Shadowrocket routing template.
- `surge.conf`: Surge routing template.
- `loon.conf`: Loon routing template.
- `quantumultx.conf`: Quantumult X filter template.
- `sing-box.json`: sing-box route template.

## Placeholders

- `{{PROXIES}}`: node list generated for the target client.
- `{{PROXY_GROUPS}}`: optional pre-generated proxy groups.

## Notes

- Rule order follows `mihomo.yaml`.
- Remote rule-set formats differ by client. Replace or validate the URLs before
  using a template in production.
- Sub-Store file scripts can use `produceArtifact` to read a collection and
  inject its output into these templates.
- For full configs, merge these routing sections into the client's complete
  configuration instead of importing them as standalone files.
